# HomePro Services — Local Service Business Website

A conversion-focused website redesign for a local home services business (plumbing, HVAC, electrical). Built for **Task 1: Local Service Business Website Redesign**.

## Features

- **Conversion-optimized layout** — Clear value prop, lead capture forms, and CTAs on every page
- **Trust elements** — Reviews, licenses, guarantees, testimonials
- **Mobile-responsive** — Works on phones, tablets, and desktop
- **Lead capture** — Inline quote form (homepage) + full contact form (contact page)
- **Service positioning** — Dedicated services page with clear benefits and CTAs

## Project Structure

## How to Run

1. Open `index.html` in a browser, or
2. Use a local server (e.g. `npx serve .`) and visit the URL shown
